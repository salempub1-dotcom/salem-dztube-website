## النتائج

- القديم: محتوى Hostinger AI Builder، وDNS عام يشير إلى Hostinger. الدومين متحقق ضمن حساب فريق Vercel، لكن اسم مشروع قديم مرتبط به لم يمكن إثباته. لا نخمن اسماً.
- الجديد: عنوان الموقع المقدم يعمل، مع الرئيسية والمقالات الستة والمقال الفردي والإدارة وصفحات الثقة. المشروع المحدد من المستخدم هو salem-dztube-website-ab5g؛ توجد نسخة ثانية من المستودع في salem-dztube-website. تعيين الهدف النهائي يحتاج صلاحية قراءة Domains وProduction وGit للمشروعين.
- حفظت نسخة main الحالية بفرع backup/before-domain-migration-20261024. لم أحذف الموقع القديم أو مستودعه، ولم أدعِ الحصول على نسخة كاملة من مصدره غير المتاح.
- جهزت الدومين الرسمي في Canonical وOG وSchema والمشاركة وrobots وSitemap، على فرع منفصل فقط. لا تغييرات في تصميم الرئيسية أو ترتيب أقسامها أو ملفات صورها أو CSS.
- جهزت 301 لثلاثة مسارات قديمة، مع صيغ slash: معرض الفيديوهات وصفحة الفيديوهات إلى /videos/، والتواصل إلى /contact/. المقدمة القديمة محفوظة في /------/، والمتجر الفارغ يعيد410 دون تحويل مضلل.
- نجح npm run check: 25 اختباراً. نجح فحص 24 صفحة/حالة عند390 و1440px محلياً مع محتوى Supabase المنشور الحقيقي: لا overflow أو أخطاء JavaScript أو مخالفات axe A/AA مرصودة. نجح فحص Canonical/Sitemap والمقال المنشور والتحويلات301 و410 و404 عبر scripts/check-domain.mjs.
- نجح فحص منع الفهرسة والإعلانات في بناء Preview. تحقق المحتوى الأساسي للمقال وصفحة الفيديوهات دون JavaScript. لم يُختبر دخول المدير بكلمة مرور حقيقية، ولم تتغير RLS أو الجداول أو Supabase Auth config.
- HTTPS الحالي متاح للاسمين، والتحويلات الحالية من HTTP وwww إلى https://salemdztube.com/ هي301. شهادة Vercel المستقبلية وانتشار DNS بعد النقل لم يُختبرا لأن النقل لم يحدث.
- Search Console غير متصلة؛ الفهرسة والزيارات وإرسال Sitemap غير منفذة. AdSense غير متصل؛ حالة القبول وAuto ads غير متحققة. القديم يحمّل SDK الناشر المرسل، وads.txt القديم404. المرشح لا يحمّل SDK وتكامل التحقق فيه فقط؛ لا تغيير في حساب Google.

## ما يمنع التحويل الآن

الاتصال بـVercel لا يكشف المشاريع المطلوبة:404 وقوائم خالية، والمعاينات محمية. كذلك DNS الفعلية خارج Vercel ولا توجد أداة Hostinger DNS متصلة. يلزم تأكيد الوصول وتسجيل معرّف المشروع ونشره ولقطة منطقة DNS القابلة للتحرير، واختبار Preview فعلياً، والحصول على القيم المطلوبة من Vercel قبل عرض موافقة التحويل النهائي.

لم تُكتب قيم DNS مفترضة. البريد وخوادم الأسماء وسائر الخدمات محفوظة. يرجع الموقع إلى النسخة القديمة، عند الحاجة، بإعادة سجلات الويب المعدلة إلى النسخة الموثقة قبيل النقل، أو بإعادة Project Domain إلى المشروع القديم إذا ثبت وجود ارتباط Vercel فعلي. لا حاجة لحذف مشروع للرجوع.
