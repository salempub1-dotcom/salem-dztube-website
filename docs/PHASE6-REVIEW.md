## الأخطاء والتحسينات المنفذة

- كان حقل غلاف المحرر من نوع URL رغم حفظ صورة المسودة بصيغة `private:...`، مما يمنع تحقق النموذج عند إعادة الحفظ؛ أصبح حقلاً نصياً مع تحقق برمجي صارم من HTTPS أو مسار Storage خاص صالح.
- كان إلغاء النشر يمحو تاريخ النشر؛ يحافظ المحرر عليه الآن، مع تحكم صريح في التاريخ بتوقيت الجزائر ودعم موعد مستقبلي لا يظهر للعامة قبل حلوله. آخر تحديث يُحفظ تلقائياً ويُعرض للمدير. لا تغييرات في الجداول أو السياسات.
- أضيف دعم روابط داخلية وHTTPS آمنة وجداول دلالية مع تمرير داخل الجدول على الهاتف. HTML المدخل لا يُنفَّذ. المعاينة تستعمل الغلاف المحلي المرجعي إذا لم يوجد غلاف CMS.
- أضيفت BreadcrumbList وPerson/Organization/WebSite مع هوية مترابطة، وتواريخ HTML time، ورابط واضح للعودة إلى المقالات. تعرض المقالات ذات الصلة من بقية المواضيع عندما لا يوجد مقال آخر من التصنيف نفسه.
- أضيف عدد نتائج الأرشيف وعنوان خاص لبحث/تصنيف/صفحة، وتحسين Canonical للمرشحات مع استمرار noindex لنتائج البحث والتصفية. ترقيم الصفحات يحفظ البحث والتصنيف، والصفحات غير الموجودة تبقى404. الروابط القديمة تحافظ على تحويل308 الدائم.
- أصبحت بطاقات الفيديوهات الخمسة ضمن HTML الناتج عن البناء، وتبقى ظاهرة عند تعذر جلب JSON. أضيف تحميل مبكر للصورة الرئيسية وتخزين ملفات assets لمدة يوم مع إعادة تحقق خلفية.
- حافظت الواجهة على ألوانها وصورتها وخطوطها وتكوينها وترتيب أقسامها. لا تغيير Root Directory أو rewrites أو الدومين. أظهرت لقطات الهاتف والحاسوب الأقسام الأصلية بلا تمرير أفقي.
- راجعت صفحات التعريف والتواصل والخصوصية والكوكيز والشروط وروابط Footer؛ كانت موجودة وكاملة للوضع الحالي، فلم أستبدلها بنصوص عامة. لا صفحة إفصاح تزعم وجود روابط تابعة لم يتم إثباتها. يلزم الإفصاح عند إدراج علاقة فعلية.

## نتائج الاختبار وحدودها

- `npm run check`: البناء و26 اختباراً ناجحاً. اختبارات XSS والروابط والجداول والتواريخ والـSchema وPagination والمسارات والأصول وAdSense/Preview.
- Playwright محلي مع بيانات Supabase المنشورة الحقيقية:20 صفحة/حالة عند عرض390 و1440px؛ لا أخطاء JavaScript مرصودة أو صور محملة مكسورة أو overflow أو مخالفات axe WCAG A/AA. المحتوى الرئيسي للمقالات والفيديوهات متاح دون JavaScript.
- فحص روابط وأصول محلي مستقل من sitemap، مع فحص404 وسياسة منع فهرسة الإدارة.
- اختبار محرر **معزول بمصدر Supabase محاكى**: حفظ مسودة ذات غلاف خاص، تحويل التاريخ، معاينة جدول وروابط. لا يُثبت تسجيل الدخول بكلمة مرور الحساب الحقيقي؛ هذا الاختبار ما زال مطلوباً بجلسة مسؤول مصرح بها.
- RLS حي: مسودة فحص خاصة أنشئت للاختبار فقط لم تظهر للمجهول، ورابطها العام404، والكتابة المجهولة رُفضت. أزيلت مسودة الفحص بعد ذلك، وتبقى ست مقالات منشورة دون تعديل بياناتها. تحقق وجود عضوية المدير المعتمد وسياسات Storage والحد5MiB وأنواع JPEG/PNG/WebP؛ لا Service Role في المتصفح.
- `npm audit --omit=dev`:0 ثغرات مُبلّغ عنها وقت الفحص.
- Lighthouse محلي للهاتف، تشغيل واحد قبل/بعد، بنفس الإعدادات: الأداء94، الوصول100، SEO100، أفضل الممارسات100. LCP≈2.93s، CLS≈0.0032، TBT=0ms في الحالتين. لا تحسن مقاس يُدّعى؛ LCP يحتاج متابعة للوصول إلى النطاق الجيد. لا بيانات INP أو CrUX ميدانية؛ نتيجة SEO100 ليست ضمان فهرسة أو ترتيب.
- معاينة build مع VERCEL_ENV=preview: noindex، robots تمنع الفهرسة، ولا وسم ناشر أو ads.txt تجاري أو SDK. استُعيد البناء الطبيعي بعد التحقق.
- بيانات JSON-LD فُحصت برمجياً، ولم يُجر Rich Results Test أو فحص Search Console الحقيقي لعدم اتصال الحساب وحماية المعاينة.

## AdSense والمتبقي قبل تشغيله

المعرّف المرسل من المالك `ca-pub-4932171916184035` محفوظ للتحقق فقط. لا أداة AdSense متصلة، لذلك ملكية الحساب وحالة Sites والقبول غير متحققة. لا SDK أو وحدات أو طلبات إعلان أو مراجعة جديدة. `ads.txt` ووسم التحقق بلا تكرار، مع استثناء الإدارة و404 وPreview. منطقة النص موسومة كإعلانات معطلة للتحضير دون مساحات مرئية.

يلزم مراجعة الحساب والموقع الصحيحين ثم موافقة سالم، وتركيب CMP المناسبة عند الحاجة، وتحديث الإفصاحات، وضبط استثناءات Auto ads والـCSP واختبار الأداء والمواضع. لم أقل إن التفعيل مكتمل. التفاصيل في [خطة AdSense](ADSENSE-SETUP.md)، ومراجعها الرسمية من Google.

تنبيه Supabase المتبقي: حماية كلمات المرور المسرّبة غير مفعّلة؛ راجع [إعدادها الرسمي](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection). لم أغيّر اشتراك الخدمة أو إعداداً قد يؤثر في التكلفة لتفعيلها.
