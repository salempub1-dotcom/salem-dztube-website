# صور المقالات — SalemDZTube

إضافة عرض فقط للمقالات المنشورة التالية، دون تعديل نصوصها أو قاعدة البيانات:

- `cod-order-tracking-algeria`
- `ai-product-descriptions-checklist`
- `mobile-product-page-checklist`

لكل مقال غلاف أصلي بصيغة WebP (أقل من 50 كيلوبايت)، ورسم توضيحي SVG عربي مع وصف بديل وتعليق يوضح طبيعة المثال. تُعرض الأغلفة في الرئيسية والأرشيف وصفحة المقال، وتستخدم روابط مطلقة في Open Graph وArticle schema. تبقى أغلفة CMS المرفوعة ذات الأولوية. خريطة العرض في `lib/article-visuals.js`؛ المقالات الأخرى لا تتأثر.

لم يتغير تصميم الرئيسية أو صورتها، ولم تُضف شيفرة إعلان أو تتبع. الرسوم أمثلة تعليمية وليست صور منتجات للبيع أو نتائج حملات حقيقية.

## التوليد

الأغلفة أُنشئت بأداة توليد الصور المدمجة، ثم حُولت إلى WebP بعرض يقارب 1200 بكسل دون تعديل محتواها. الرسوم التفسيرية SVG رُسمت برمجياً لضبط الكلمات والمراحل، ولا تتضمن موارد خارجية أو سكربتات.

مواصفات البرومبتات المشتركة: غلاف تحريري أصلي أفقي 16:9؛ مشهد مجسم واقعي بملمس واضح؛ خلفية استوديو بيضاء؛ ألوان #d7192c و#19191d والأبيض؛ ظلال ناعمة؛ مساحة آمنة للاقتطاع؛ دون نصوص أو علامات مائية أو ادعاءات مبيعات.

- COD: طرد أبيض بشريط أحمر وهاتف عليه قائمة متابعة مجردة وشاحنة توصيل، مع نقاط مسار حمراء وسوداء.
- AI: حاسوب بواجهة نصية مجردة، منظم مكتب أبيض، شريط قياس وبطاقة تحقق من المواصفات، وشبكة نقاط مجردة ترمز للذكاء الاصطناعي.
- Mobile: هاتف بصفحة منتج توضيحية تتضمن صورة طرد وخطوطاً مجردة وزر طلب أحمر، إلى جانبه طرد وبطاقة تحقق.

## التحقق

`npm run check` يبني الموقع ويشغل الاختبارات، ومنها وجود الأصول في `dist`، وأولوية غلاف CMS، ورفض روابط الصور غير الآمنة، وصحة روابط صور SEO. راجع اختبار المتصفح المحلي على 390 و1440 بكسل قبل الدمج. النشر النهائي يتطلب دمج الفرع بعد مراجعة المستخدم.
