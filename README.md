# SalemDZTube — الموقع الحالي ونظام المقالات

تم الاحتفاظ بواجهة الصفحة الرئيسية الأصلية وألوانها وصورتها وأقسامها. أعيدت هيكلة الملفات المسطحة من رفع GitHub السابق؛ `index.html` كان يحتوي صفحة «من نحن»، والصفحة الرئيسية كانت باسم `index (9).html`.

## التشغيل

Node.js 22 أو 24:

```bash
npm ci --ignore-scripts
npm run check
npm run dev
```

افتح http://localhost:4173. لا تستخدم خادم ملفات ثابتاً فقط؛ صفحات المقالات وخريطة الموقع تُقدّم من Node.js.

## الهيكلة

- `index.html`, `styles.css`, `main.js`, `site.js`: واجهة SalemDZTube الأصلية وتحسيناتها.
- `assets/`: الصورة الأصلية ونسخة WebP والخط Cairo بنفس الأوزان، مستضاف محلياً مع رخصته.
- `content/videos.json`: بيانات الفيديوهات المقدمة سابقاً. المعرف المؤكد الوحيد هو `DPVB2GNKNzQ`. بقية البطاقات تصل إلى القناة؛ لا نخمن روابط الفيديوهات.
- `admin/`: لوحة إدارة عربية، SDK مجمّع محلياً، جلسة في `sessionStorage`، تحقق عضوية `site_admins`، نشر/إلغاء نشر، تصنيفات، صور، معاينة.
- `lib/`: تنسيق آمن ومشترك، قالب الموقع وقراءة Supabase بالمفتاح العام فقط.
- `api/render.js`: HTML من الخادم لأرشيف المقالات وصفحاتها وsitemap؛ قراءة المنشور فقط، 404 حقيقية، no-store لإخفاء المقال فور إلغاء نشره.
- `scripts/legal.mjs`: المصدر المعتمد لصفحات التعريف والتواصل والخصوصية والارتباط والشروط.
- `scripts/build.mjs`: يبني `dist/` بقائمة ملفات مسموحة. لا ينشر المسودات أو SQL أو ملفات التوثيق.
- `tests/`: فحوص المحتوى وSEO والأمان والتوجيه.
- `db/applied-hardening.sql`: سجل التغييرات الإضافية التي نُفذت على قاعدة SalemDZTube الحالية، وليس سكربت إعادة إنشائها.
- `docs/`: المرجع القديم ومسوداته غير المنشورة والخطة التحريرية. لا تدخل هذه الملفات في النشر.

## Vercel

المشروع المقصود حصراً: `salem-dztube-website` في `elmiraj1`، المستودع الحالي، وفرع الإنتاج `main`.

`vercel.json` يحدد build=`npm run build` وoutput=`dist`؛ لا يعيد توجيه `/` إلى المقالات. لم تُغيّر إعدادات المشروع البعيد أو Root Directory. يجب فحصها عند استعادة صلاحية المشروع؛ الجذر الصحيح هو جذر هذا المستودع. فرع التطوير يستعمل Preview فقط، ولا يُدمج قبل الموافقة.

## Supabase

المرجع الحالي: `dzlkwzzcmbydbsdisulx`. لا مشروع جديد ولا إعادة إنشاء للجداول. لا تحتاج الواجهة أو SSR إلى service role. المفتاح في `lib/config.js` و`config/supabase.js` عام publishable؛ الحماية بجدول المدير وRLS.

`article-drafts`: خاص بالمسودات. `article-images`: صور منشورة عامة. كلاهما يقبل JPEG/PNG/WebP حتى 5 MiB، والكتابة للمدير فقط. نسخة صورة سبق نشرها يمكن أن تبقى متاحة برابطها بعد إلغاء نشر المقال؛ النص والمسودة لا يُعرضان للعامة. الصور الخارجية التي تدخلها كرابط HTTPS تبقى تحت سياسة مضيفها.

لا يمكن تغيير slug لمقال محفوظ من واجهة الإدارة تجنباً لكسر الروابط. `/articles/read/?slug=...` يعيد 308 إلى الرابط الجديد. Slug `read` محجوز للروابط السابقة.

## نتائج مؤكدة وحدود

البناء واختبارات Node نجحت. جرى اختبار إنشاء/قراءة/نشر/إلغاء نشر في قاعدة البيانات بمعاملة ROLLBACK؛ لا محتوى تجريبي باقٍ. الاختبار لا يُعد إثباتاً لتسجيل دخول المدير بكلمة المرور من المتصفح. لا أسرار طُلبت أو أُضيفت.

مراقب Supabase الأمني يعرض تحذيراً عن تعطيل فحص كلمات المرور المسرّبة. لم تُفعّل خدمة قد تعتمد على الخطة أو تغيّر إعدادات الحساب دون مراجعة.

AdSense غير مفعّل ولم يُطلب القبول. انظر `docs/EDITORIAL-PLAN.md`.
